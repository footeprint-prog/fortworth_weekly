# Product roadmap

## Current release

- Explainable score and fit tier
- Normalized housing categories matching the locator priority order
- Runtime JSON validation
- Requirement-ready and specific-listing filters
- Operations metrics and high-priority coverage gaps
- Accessible keyboard behavior and improved drawer focus handling
- GitHub Pages deployment workflow

## Next high-value work

1. **Automated duplicate detection** across URL variants and reposted units
2. **Listing freshness service** to flag removed, stale, or price-changed listings
3. **Contact pipeline** with response deadlines and structured outcomes
4. **Map and commute layer** using approximate coordinates or neighborhoods
5. **Search adapters** for owner-direct, travel-clinician, and property-manager channels
6. **Historical price tracking** and lead change diffs
7. **Shared authenticated decisions** when browser-local state becomes limiting
8. **End-to-end tests** for loading, filtering, export/import, and lead actions
